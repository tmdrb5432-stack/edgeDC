# 전국 데이터센터 영업 현황

## GitHub Pages 적용
1. 압축을 풀고 `index.html`을 기존 GitHub 저장소의 최상위 `index.html`에 덮어씁니다.
2. Commit changes를 누르고 GitHub Pages 배포를 기다린 뒤 사이트를 새로고침합니다.
3. 처음 올릴 경우 Settings → Pages → Deploy from a branch → main → / (root)를 선택합니다.

## 자료 범위
- 2026-11-12 기준 초기 스냅샷이며 자동으로 갱신되지 않습니다.
- 참고: https://dc.namepf.com/ 의 건축 인허가 대장 기반 자료와 기존 공개기사 조사 목록을 결합했습니다. 참고 사이트는 2020년 이후 특정 건축 용도 중심이므로 전국의 모든 운영·계획 사업을 포함하지 않습니다.
- 총 168행은 개별 시설 168곳을 뜻하지 않습니다. 같은 인허가 번호의 중복은 제거했지만, 다른 인허가 건이나 서로 다른 이름의 동일 사업은 함께 남아 있을 수 있습니다.
- `허가`: 건축허가일 / `착공`: 대장상 실제착공일 / `준공`: 사용승인일. 목표 시점이나 보도는 별도 표시합니다.
- RFS는 서비스 준비 완료 시점입니다. 건축물 준공·사용승인 및 운영 시작과 구분하므로 확인되지 않으면 빈값으로 둡니다.
- 수전 기준이 불명확한 MW 값은 수전규모에 기입하지 않았습니다. 기존 조사 사업은 원문 추가 확인이 필요합니다.
- 인허가 자료 좌표는 법정동 대표점입니다. 기존 사업도 대략적인 위치이며 실제 부지를 뜻하지 않습니다. 좌표가 없는 사업은 지도에 표시하지 않습니다.
- 사업자와 기사 연결은 참고용입니다. 원문에서 사업 동일 여부, 최신 상태 및 시점을 확인하세요.

OpenStreetMap 지도는 인터넷 연결이 필요하며 공개 타일 서버 정책상 차단되거나 서비스되지 않을 수 있습니다. GitHub Pages는 일반적으로 공개 사이트이므로 민감한 영업정보를 올리지 마세요.
